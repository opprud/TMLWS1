# Put the generated model here

This folder must contain `xor_model.h`, generated by Part 1:

```bash
cd ../../xor-train
python train_xor.py
cp xor_model.h ../xor-device/include/
```

The header is intentionally **not** checked in — regenerating it is part of the
exercise (and of the workflow you'd use in a real project: model artefacts are
build outputs, produced reproducibly by a training script).
